# Flappy Glide

Flappy Glide is a highly optimized, high-performance HTML5 Canvas web game heavily inspired by the classic "Flappy Bird". 
It features a smooth gameplay loop, dynamically scaling difficulty, and a robust, paginated local leaderboard system.

## Features
- **100% Canvas Rendering**: Zero image-loading lag. All graphics are drawn natively using high-performance Canvas 2D API shapes.
- **Dynamic Difficulty**: The game progressively gets harder the longer you survive, with increasing speeds and tightening pipe gaps.
- **Global Leaderboard System**: A dedicated leaderboard interface that tracks all players using `localStorage`, supporting unlimited entries and paginated navigation.
- **Responsive Controls**: Supports mouse click, spacebar, and touch inputs seamlessly.
- **Fluid UI Animations**: Modern, clean, flat-design UI with hover transitions and screen fade-ins.

## How to Play
1. Clone the repository.
2. Open `index.html` in your favorite modern web browser.
3. Enter your name on the Welcome Screen.
4. Click "START GAME".
5. Use the **Spacebar**, **Left Mouse Click**, or **Touch** to fly and avoid the pipes!

## Technologies Used
- HTML5 Canvas
- Vanilla JavaScript (ES6+)
- Vanilla CSS3
