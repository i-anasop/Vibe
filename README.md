# Flappy Glide

**[PLAY THE GAME LIVE NOW!](https://i-anasop.github.io/Vibe/)**

A highly polished, 100% Canvas-rendered web game inspired by the classic Flappy Bird. 
Dodge the pipes, beat the dynamic gravity, and climb the live global leaderboard!

### Features
- **Zero-Lag Rendering:** Built entirely with native HTML5 Canvas for buttery-smooth performance.
- **Global Leaderboard:** Fully integrated with LootLocker. Compete with players worldwide!
- **Dynamic Difficulty:** The game gets faster and the gaps get tighter as your score increases.
- **Responsive Controls:** Play seamlessly using Mouse, Spacebar, or Mobile Touch.

*Built from scratch with Vanilla JavaScript. No engines, no bloat.*
