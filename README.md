# 🐦 Flappy Glide | Official Web Game

[![Live Demo](https://img.shields.io/badge/demo-online-brightgreen.svg)](https://i-anasop.github.io/Vibe/)
[![Platform](https://img.shields.io/badge/platform-mobile%20%7C%20web-blue.svg)](#)

A professional, mobile-first reimagining of the classic "Flappy" genre. Built with a focus on premium aesthetics, smooth physics, and global competition.

## ✨ Features

- **Studio Character Design:** High-definition vector-style bird with smooth flight physics.
- **Global Leaderboard:** Compete in real-time with players worldwide via LootLocker integration.
- **Premium Skin System:** Unlock exclusive **Golden** and **Neon** skins by achieving high scores.
- **Mobile-First UI:** Glassmorphic interface designed for touch devices with portrait-only orientation lock.
- **Anti-Cheat Engine:** Dynamic pipe generation variance and orientation monitoring to ensure fair play.

## 🕹️ How to Play

1. **Enter Your Name:** Set your pilot identity for the global ranks.
2. **Tap/Space to Jump:** Keep your bird in the air and navigate through the gaps.
3. **Avoid the Pipes:** Hitting a pipe or the ground will end your run.
4. **Unlock Skins:** 
   - **Standard:** The classic look.
   - **Golden:** Reach a score of **20** to unlock.
   - **Neon Blue:** Reach a score of **50** to unlock.

## 🛠️ Tech Stack

- **Frontend:** Vanilla JavaScript, HTML5 Canvas, Modern CSS3 (Glassmorphism).
- **Backend:** [LootLocker API](https://lootlocker.com/) for Session Management and Leaderboards.
- **Responsiveness:** Implemented via `100dvh` and orientation-aware media queries.

## 🚀 Deployment

The project is hosted on **GitHub Pages**. Any changes pushed to the `main` branch are automatically deployed.
